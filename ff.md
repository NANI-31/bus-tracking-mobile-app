## §27. First 90 Days Onboarding Roadmap

> Use this when you land a role. First impressions compound.

### Days 1–30: Learn & Listen

| Priority                    | Action                                                                     |
| --------------------------- | -------------------------------------------------------------------------- |
| **Understand the codebase** | Clone, run locally, read README + architecture docs                        |
| **Shadow teammates**        | Ask to join standups, code reviews, design reviews as observer             |
| **Map the data**            | Understand what data exists, where it lives, who owns it                   |
| **Meet stakeholders**       | 1:1 with direct manager, skip-level, adjacent team leads                   |
| **Identify quick wins**     | Bug fixes, documentation gaps, small improvements you can own              |
| **Never skip questions**    | Write down every question; ask in batches to avoid interrupting constantly |

**Goal**: By Day 30 — have a first PR merged, know the team's top 3 priorities, understand the deployment pipeline.

---

### Days 31–60: Contribute & Build Credibility

| Priority                 | Action                                                                  |
| ------------------------ | ----------------------------------------------------------------------- |
| **Own a feature or fix** | Take a meaningful ticket end-to-end with minimal hand-holding           |
| **Run experiments**      | Propose and run one ML experiment or A/B test with clear hypothesis     |
| **Write documentation**  | Document something that confused you when you joined                    |
| **Ask for feedback**     | Mid-point 1:1 with manager: "What's one thing I should do differently?" |
| **Build relationships**  | Lunch / virtual coffee with 1 person per week across the team           |

**Goal**: By Day 60 — independently shipped one feature, have 2–3 PRs merged, manager knows your work style.

---

### Days 61–90: Lead & Shape

| Priority                   | Action                                                                             |
| -------------------------- | ---------------------------------------------------------------------------------- |
| **Propose an improvement** | Identify one technical debt item or process gap and propose a fix                  |
| **Present something**      | Demo your work in a team meeting or tech talk                                      |
| **Set 6-month goals**      | Agree with manager on what success looks like in 6 months                          |
| **Build a reputation**     | Respond quickly in Slack, review others' PRs, be the person who unblocks teammates |

**Goal**: By Day 90 — trusted team member with clear 6-month roadmap, actively contributing to team decisions.

### 28.2 Negotiation Script

**When an offer arrives:**

```
"Thank you so much for the offer — I'm genuinely excited about this
opportunity and the team. I'd like to take a day or two to review
the full package. Would that work?"

[After reviewing]

"I've reviewed the offer carefully. I'm very enthusiastic about the role.
Based on my research into the market and comparable roles, I was expecting
a base closer to [X]. Is there flexibility on the base salary?"

If they push back:
"I understand. If base is fixed, could we explore [signing bonus /
additional equity / accelerated review timeline / extra PTO]?"
```

**Rules:**

- Never accept on the spot — always ask for time
- Always negotiate — 85% of offers have room to move
- Have a BATNA (Best Alternative To Negotiated Agreement) — if you have another offer, say so diplomatically
- Never give a number first if you can avoid it — "I'm flexible; what's the range for this role?"

## §29. Common Pitfalls & How to Avoid Them

| Pitfall                                     | Why It Happens                    | Prevention                                                                    |
| ------------------------------------------- | --------------------------------- | ----------------------------------------------------------------------------- |
| **Applying before portfolio is ready**      | Urgency / anxiety                 | Hard gate: do not apply until ≥3 flagship projects are live and deployable    |
| **Not tracking applications**               | Optimism that memory will suffice | Start tracker on day 1 — no exceptions                                        |
| **Cramming DSA the night before**           | Procrastination                   | 5 LeetCode problems per day, every day — no cram sessions                     |
| **Memorising ML definitions**               | Surface-level prep                | Always explain from first principles — interviewers probe with follow-ups     |
| **Not reading JD carefully**                | Volume-focused applying           | Spend 10 minutes reading JD; map 3 bullets in resume to 3 JD requirements     |
| **Skipping salary research**                | Awkwardness about money           | Know your number before every phone screen                                    |
| **Over-explaining in behaviorals**          | Nervousness                       | STAR: maximum 2 minutes. Practice out loud, not just in your head             |
| **Not following up**                        | Fear of rejection                 | Polite follow-up after 7 days is professional, not pushy                      |
| **Accepting the first offer out of relief** | Relief from job search stress     | Always negotiate; always compare to market                                    |
| **Neglecting networking**                   | Introversion / process focus      | 1 outreach message per day — this is the highest-ROI activity in a job search |

## §27. First 90 Days Onboarding Roadmap

> Use this when you land a role. First impressions compound.

### Days 1–30: Learn & Listen

| Priority                    | Action                                                                     |
| --------------------------- | -------------------------------------------------------------------------- |
| **Understand the codebase** | Clone, run locally, read README + architecture docs                        |
| **Shadow teammates**        | Ask to join standups, code reviews, design reviews as observer             |
| **Map the data**            | Understand what data exists, where it lives, who owns it                   |
| **Meet stakeholders**       | 1:1 with direct manager, skip-level, adjacent team leads                   |
| **Identify quick wins**     | Bug fixes, documentation gaps, small improvements you can own              |
| **Never skip questions**    | Write down every question; ask in batches to avoid interrupting constantly |

**Goal**: By Day 30 — have a first PR merged, know the team's top 3 priorities, understand the deployment pipeline.

---

### Days 31–60: Contribute & Build Credibility

| Priority                 | Action                                                                  |
| ------------------------ | ----------------------------------------------------------------------- |
| **Own a feature or fix** | Take a meaningful ticket end-to-end with minimal hand-holding           |
| **Run experiments**      | Propose and run one ML experiment or A/B test with clear hypothesis     |
| **Write documentation**  | Document something that confused you when you joined                    |
| **Ask for feedback**     | Mid-point 1:1 with manager: "What's one thing I should do differently?" |
| **Build relationships**  | Lunch / virtual coffee with 1 person per week across the team           |

**Goal**: By Day 60 — independently shipped one feature, have 2–3 PRs merged, manager knows your work style.

### Days 61–90: Lead & Shape

| Priority                   | Action                                                                             |
| -------------------------- | ---------------------------------------------------------------------------------- |

**Goal**: By Day 90 — trusted team member with clear 6-month roadmap, actively contributing to team decisions.

### 28.2 Negotiation Script

**When an offer arrives:**

```
"Thank you so much for the offer — I'm genuinely excited about this
opportunity and the team. I'd like to take a day or two to review
the full package. Would that work?"

[After reviewing]

"I've reviewed the offer carefully. I'm very enthusiastic about the role.
Based on my research into the market and comparable roles, I was expecting
a base closer to [X]. Is there flexibility on the base salary?"

If they push back:
"I understand. If base is fixed, could we explore [signing bonus /
additional equity / accelerated review timeline / extra PTO]?"
```

**Rules:**

- Never accept on the spot — always ask for time
- Always negotiate — 85% of offers have room to move
- Have a BATNA (Best Alternative To Negotiated Agreement) — if you have another offer, say so diplomatically
- Never give a number first if you can avoid it — "I'm flexible; what's the range for this role?"

## §29. Common Pitfalls & How to Avoid Them

| Pitfall                                     | Why It Happens                    | Prevention                                                                    |
| ------------------------------------------- | --------------------------------- | ----------------------------------------------------------------------------- |
| **Applying before portfolio is ready**      | Urgency / anxiety                 | Hard gate: do not apply until ≥3 flagship projects are live and deployable    |
| **Not tracking applications**               | Optimism that memory will suffice | Start tracker on day 1 — no exceptions                                        |
| **Cramming DSA the night before**           | Procrastination                   | 5 LeetCode problems per day, every day — no cram sessions                     |
| **Memorising ML definitions**               | Surface-level prep                | Always explain from first principles — interviewers probe with follow-ups     |
| **Not reading JD carefully**                | Volume-focused applying           | Spend 10 minutes reading JD; map 3 bullets in resume to 3 JD requirements     |
| **Skipping salary research**                | Awkwardness about money           | Know your number before every phone screen                                    |
| **Over-explaining in behaviorals**          | Nervousness                       | STAR: maximum 2 minutes. Practice out loud, not just in your head             |
| **Not following up**                        | Fear of rejection                 | Polite follow-up after 7 days is professional, not pushy                      |
| **Accepting the first offer out of relief** | Relief from job search stress     | Always negotiate; always compare to market                                    |
| **Neglecting networking**                   | Introversion / process focus      | 1 outreach message per day — this is the highest-ROI activity in a job search |
